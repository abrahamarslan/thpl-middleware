# Recurring Invoices

Recurring invoices are invoices that are created and sent to your customers on a recurring schedule.

### Attributes

| Attribute                      | Type    | Description                                                                                                  |
| :----------------------------- | :------ | :----------------------------------------------------------------------------------------------------------- |
| **recurring_invoice_id**       | string  | Unique ID of the recurring invoice generated by the server.                                                  |
| **recurrence_name**            | string  | Unique name for the recurring profile given by the user. Max-length [100]                                    |
| **reference_number**           | string  | The Order number of the Recurring Invoice.                                                                   |
| **customer_name**              | string  | Name of the customer to whom the recurring invoice is raised.                                                |
| **customer_id**                | string  | Customer ID of the customer for whom the recurring invoice is raised.                                        |
| **currency_id**                | string  | The currency id of the currency.                                                                             |
| **currency_code**              | string  | The currency code in which the invoice is created.                                                           |
| **start_date**                 | string  | The date on which the recurring invoice starts.                                                              |
| **end_date**                   | string  | The date on which the recurring invoice expires.                                                             |
| **last_sent_date**             | string  | The date at which the last invoice was sent.                                                                 |
| **next_invoice_date**          | string  | The date at which next invoice is to be sent.                                                                |
| **recurrence_frequency**       | string  | The frequency of time interval at which the invoice is to be generated.                                      |
| **repeat_every**               | integer | The period between every recurrency frequency.                                                               |
| **status**                     | string  | Status of the recurring invoice. This can be `active`, `stopped` or `expired`.                               |
| **contact_persons_associated** | array   | Contact Persons associated with the transaction.                                                             |
| **line_items**                 | array   | Line items of an invoice.                                                                                    |
| **payment_terms**              | integer | Payment terms in days. E.g: 15,30,60.                                                                        |
| **payment_terms_label**        | string  | Used to override the default payment terms label.                                                            |
| **discount**                   | string  | Discount applied to the invoice. It can be either in % or in amount.                                         |
| **is_discount_before_tax**     | boolean | Used to specify how the discount has to applied. Either before or after the calculation of tax.              |
| **discount_type**              | string  | How the discount is specified. Allowed values: `entity_level` and `item_level`.                              |
| **is_inclusive_tax**           | boolean | Used to specify whether the line item rates are inclusive or exclusive of tax.                               |
| **shipping_charge**            | double  | Shipping charges applied to the invoice.                                                                     |
| **adjustment**                 | double  | Adjustments made to the invoice.                                                                             |
| **adjustment_description**     | string  | Customize the adjustment description. E.g: Rounding off.                                                     |
| **place_of_supply**            | string  | [India, GCC Only] Place where the goods/services are supplied to.                                            |
| **gst_no**                     | string  | [India Only] 15 digit GST identification number of the customer.                                             |
| **gst_treatment**              | string  | [India Only] GST treatment: `business_gst`, `business_none`, `overseas`, `consumer`.                         |
| **tax_treatment**              | string  | [GCC, Mexico, Kenya, South Africa Only] VAT treatment for the contact.                                       |
| **vat_treatment**              | string  | [UK Only] VAT treatment for the invoices (`uk`, `eu_vat_registered`, `overseas`, etc.).                      |
| **is_reverse_charge_applied**  | boolean | [South Africa Only] Used to specify whether the transaction is applicable for Domestic Reverse Charge (DRC). |
| **cfdi_usage**                 | string  | [Mexico Only] Choose CFDI Usage.                                                                             |

## Update a recurring invoice using a custom field's unique value

Update a recurring invoice by providing a unique custom field's API name and value.

`OAuth Scope : ZohoBooks.invoices.UPDATE`

### Headers

| Name                          | Type    | Required | Description                                                                              |
| :---------------------------- | :------ | :------- | :--------------------------------------------------------------------------------------- |
| **X-Unique-Identifier-Key**   | string  | **Yes**  | Unique CustomField Api Name                                                              |
| **X-Unique-Identifier-Value** | string  | **Yes**  | Unique CustomField Value                                                                 |
| **X-Upsert**                  | boolean | No       | If true, creates a new invoice if no record is found with the unique custom field value. |

### Arguments

The body arguments are the same as the "Create a Recurring Invoice" endpoint.

### Query Parameters

| Name                | Type   | Required | Description            |
| :------------------ | :----- | :------- | :--------------------- |
| **organization_id** | string | **Yes**  | ID of the organization |

### Request Example

**cURL**

```bash
curl --request PUT \
  --url 'https://www.zohoapis.com/books/v3/recurringinvoices?organization_id=10234695' \
  --header 'Authorization: Zoho-oauthtoken 1000.41d9xxxxxxxxxxxxxxxxxxxxxxxxc2d1.8fccxxxxxxxxxxxxxxxxxxxxxxxx125f' \
  --header 'X-Unique-Identifier-Key: cf_unique_cf' \
  --header 'X-Unique-Identifier-Value: unique Value' \
  --header 'X-Upsert: true' \
  --header 'content-type: application/json' \
  --data '{"recurrence_name":"MonthlyInvoice","customer_id":"903000000000099"}'
```
