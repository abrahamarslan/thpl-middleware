# Credit Notes

Credit notes are created when a refund is to be made to a customer. A credit note object allows you to keep track of all credit note related information.

## Attributes

| Attribute                      | Type    | Description                                                                                                                                           |
| :----------------------------- | :------ | :---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **creditnote_id**              | string  | Unique ID of the credit note generated by the server.                                                                                                 |
| **creditnote_number**          | string  | Unique credit note number displayed in the interface. Auto-generated with CN prefix unless `ignore_auto_number_generation` is true. Max-Length [100]. |
| **date**                       | string  | The date on which the credit note is raised. Must be in `yyyy-mm-dd` format.                                                                          |
| **is_pre_gst**                 | boolean | *India only.* Applicable for transactions that fall before July 1, 2017.                                                                              |
| **place_of_supply**            | string  | *India, GCC only.* Place where the goods/services are supplied to.                                                                                    |
| **vat_treatment**              | string  | *UK only.* VAT treatment for the invoices (e.g., `uk`, `eu_vat_registered`, `overseas`).                                                              |
| **vat_reg_no**                 | string  | Enter VAT registration number.                                                                                                                        |
| **gst_no**                     | string  | *India only.* 15 digit GST identification number of the customer.                                                                                     |
| **cfdi_usage**                 | string  | *Mexico only.* Choose CFDI Usage (e.g., `acquisition_of_merchandise`, `general_expense`, etc.).                                                       |
| **cfdi_reference_type**        | string  | *Mexico only.* Choose CFDI Reference Type (e.g., `credit_note`, `return_of_merchandise`).                                                             |
| **gst_treatment**              | string  | *India only.* Choose whether the contact is GST registered/unregistered/consumer/overseas.                                                            |
| **tax_treatment**              | string  | *GCC, Mexico, Kenya, South Africa only.* VAT treatment for the credit note (e.g., `vat_registered`, `vat_not_registered`).                            |
| **is_reverse_charge_applied**  | boolean | *South Africa only.* Used to specify whether the transaction is applicable for Domestic Reverse Charge (DRC).                                         |
| **status**                     | string  | Status of the credit note (`open`, `closed`, `void`).                                                                                                 |
| **customer_id**                | string  | Unique identifier for the customer contact.                                                                                                           |
| **customer_name**              | string  | Name of the customer to whom the credit note is raised.                                                                                               |
| **contact_persons_associated** | array   | Contact Persons associated with the transaction. Contains `contact_person_id` and `communication_preference`.                                         |
| **custom_fields**              | array   | Additional fields for the Credit-Notes. Contains `index`, `value`, `label`, `data_type`.                                                              |
| **reference_number**           | string  | Optional reference number for tracking purposes.                                                                                                      |
| **email**                      | string  | Email address of the customer.                                                                                                                        |
| **total**                      | double  | Total credits raised in this credit note.                                                                                                             |
| **balance**                    | double  | The unapplied credits.                                                                                                                                |
| **location_id**                | string  | Unique identifier for the business location associated with the line item.                                                                            |
| **location_name**              | string  | Name of the location.                                                                                                                                 |
| **line_items**                 | array   | Line items of a credit note. See Line Item attributes below.                                                                                          |
| **invoices**                   | array   | List of invoices for which the credit note has been raised. Contains `invoice_id`, `invoice_number`, `amount`.                                        |
| **taxes**                      | array   | Taxes associated with the subscription.                                                                                                               |
| **currency_code**              | string  | Customer's currency code.                                                                                                                             |
| **currency_symbol**            | string  | Customer's currency symbol.                                                                                                                           |
| **billing_address**            | object  | Billing address object (address, city, state, zip, country, fax).                                                                                     |
| **shipping_address**           | object  | Shipping address object (address, city, state, zip, country, fax).                                                                                    |
| **created_time**               | string  | Time at which the credit note was created.                                                                                                            |
| **updated_time**               | string  | Time at which the credit note details were last updated.                                                                                              |
| **template_id**                | string  | Unique identifier for the credit note PDF template.                                                                                                   |
| **template_name**              | string  | Name of the default template of the creditnote.                                                                                                       |
| **notes**                      | string  | Additional notes or comments for the credit note.                                                                                                     |
| **terms**                      | string  | Terms and conditions displayed on the credit note document.                                                                                           |

## Create a credit note
Create a new credit note to record credits issued to customers.

*   **OAuth Scope:** `ZohoBooks.creditnotes.CREATE`
*   **Endpoint:** `POST /creditnotes`

### Arguments
| Argument              | Type    | Required | Description                                                                      |
| :-------------------- | :------ | :------- | :------------------------------------------------------------------------------- |
| **customer_id**       | string  | Yes      | Unique identifier for the customer contact.                                      |
| **date**              | string  | Yes      | The date on which the credit note is raised (yyyy-mm-dd).                        |
| **line_items**        | array   | Yes      | Array of line items for the credit note.                                         |
| **creditnote_number** | string  | Yes      | Unique credit note number (required if `ignore_auto_number_generation` is true). |
| **currency_id**       | string  | No       | Unique identifier for the currency.                                              |
| **is_draft**          | boolean | No       | Set to true to create the credit note in draft status.                           |
| **exchange_rate**     | string  | No       | Exchange rate for converting to base currency.                                   |
| **notes**             | string  | No       | Additional notes.                                                                |
| **terms**             | string  | No       | Terms and conditions.                                                            |
| **reference_number**  | string  | No       | Optional reference number.                                                       |
| **tax_id**            | string  | No       | Tax ID.                                                                          |
| **vat_treatment**     | string  | No       | *UK only* VAT treatment.                                                         |

*(Note: Other regional fields like `gst_no`, `place_of_supply`, `cfdi_usage` are available as per the Attributes section)*

### Query Parameters
| Parameter                         | Type    | Description                                                     |
| :-------------------------------- | :------ | :-------------------------------------------------------------- |
| **organization_id**               | string  | **Required.** ID of the organization.                           |
| **invoice_id**                    | string  | Invoice ID of the required invoice.                             |
| **ignore_auto_number_generation** | boolean | Set to true if you need to provide your own credit note number. |

### Request Example
```bash
curl --request POST \
  --url 'https://www.zohoapis.com/books/v3/creditnotes?organization_id=10234695' \
  --header 'Authorization: Zoho-oauthtoken 1000.41d9xxxxxxxxxxxxxxxxxxxxxxxxc2d1.8fccxxxxxxxxxxxxxxxxxxxxxxxx125f' \
  --header 'content-type: application/json' \
  --data '{
    "customer_id": "903000000000099",
    "currency_id": "982000000567240",
    "date": "2016-06-05",
    "is_draft": true,
    "exchange_rate": "5.5",
    "line_items": [
        {
            "item_id": "90300000081501",
            "rate": 100,
            "quantity": 1
        }
    ],
    "creditnote_number": "CN-29",
    "reference_number": "INV-384",
    "notes": "Offer for the referral"
}'
```

## Update a credit note using a custom field's unique value
Update a credit note by providing a unique custom field's API name and value in the headers.

*   **OAuth Scope:** `ZohoBooks.invoices.UPDATE`
*   **Endpoint:** `PUT /creditnotes`

### Headers
| Header                        | Required | Description                                                     |
| :---------------------------- | :------- | :-------------------------------------------------------------- |
| **X-Unique-Identifier-Key**   | Yes      | Unique CustomField Api Name.                                    |
| **X-Unique-Identifier-Value** | Yes      | Unique CustomField Value.                                       |
| **X-Upsert**                  | No       | If `true` and no record is found, a new credit note is created. |

### Request Example
```bash
curl --request PUT \
  --url 'https://www.zohoapis.com/books/v3/creditnotes?organization_id=10234695' \
  --header 'Authorization: Zoho-oauthtoken 1000.41d9xxxxxxxxxxxxxxxxxxxxxxxxc2d1.8fccxxxxxxxxxxxxxxxxxxxxxxxx125f' \
  --header 'X-Unique-Identifier-Key: cf_unique_cf' \
  --header 'X-Unique-Identifier-Value: unique Value' \
  --header 'X-Upsert: true' \
  --header 'content-type: application/json' \
  --data '{
    "customer_id": "903000000000099",
    "date": "2016-06-05",
    "line_items": [...]
}'
```
